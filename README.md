# Agent 环境卡

> 中文科研环境下，让 AI 助手认识你这台机器。

*English: Three Markdown files that teach a coding agent your machine — a one-line pointer, a hot card loaded on demand, and a cold reference for pitfalls. Built for Chinese Windows research workflows mixing GIS, statistics, and office software.*

---

## 先说清楚这是给谁用的

如果你在做研究，机器是 Windows，装了 ArcGIS、SPSS、R、Python、Office，数据在这几个软件之间来回倒手——那么你和 AI 助手的每一次对话，都是从一个**完全不认识这台机器**的状态开始的。

它不知道 R 装在 D 盘还是 C 盘，不知道你的 Python 环境不在默认位置，不知道你没装 LaTeX。它更不知道，你那批 shapefile 得先转到纯英文路径，GDAL 才肯读。

而这些东西有个共同点：**它们不是知识，是事实。** 查一次就知道，但每次新对话都得重查一遍。

这份仓库讲的就是怎么把它们固定下来，固定成三张卡。

## 那天下午

我第三次跟它说同一句话：R 装在 D 盘，用 `Rscript.exe` 跑。

第一次是周一，它问我 R 在哪。第二次是周二，新开了个对话，它又问了一遍。第三次我懒得解释，直接把路径贴了过去。贴完忽然觉得不对劲：**我在给一台机器做重复劳动，而且这份劳动每周都在重来。**

比这更烦的是踩坑。它敲 `pip install`，被我拦下；试 `import fitz`，报 FutureWarning；把一条带中文的路径交给 GDAL，报 `No such file`，可那文件明明就在那儿。每一个坑我都解释过一次。解释完就散在对话里，下次重来。

## 为什么写多少都不对

想让模型认识你的机器，最直觉的办法是写一份长文档，让它每次都读。我试过，效果不好。原因有两个，一个比一个隐蔽。

第一个是**上下文污染**。模型不是"记住"了什么，它每次都在读你给它的全部文字。所以一旦有过时的、错的、只对上次任务成立的信息混进去，它不会质疑，会照着往下推。**缺信息它会问，错信息它会自信地用。** 后者难发现得多——你很难意识到它错在哪儿，因为它的推理链是自洽的。

第二个是**注意力稀释**。上下文越长，中间那部分越容易被跳过。这个现象有研究专门讨论过，叫 "lost in the middle"。你把"别用 pip"写在三十条说明的第十七条，它很可能就是漏了——而这条恰恰是最贵的那条。

明白这两件事之后，结论其实很朴素：**这份文档不是写得越全越好，是"该出现的时候出现"越好。**

## 在中文科研环境里，这件事更严重

英文世界的 `AGENTS.md` 范例写得都不错，结构可以借鉴。但有一类条目我照抄不了——**他们的环境里不存在这些事**。

**编码是一道绕不开的坎。** PowerShell 默认 GBK，用 `Set-Content` 写个 UTF-8 文件，中文会变成乱码，**而且不报错**。你半小时后才发现 R 脚本跑不起来。路径也一样：中文字符交给 GDAL、rasterio，时不时报 `No such file`，文件在，路径也对，就是读不到。

**科研软件不按常规出牌。** ArcGIS Pro 的 arcpy、SPSS 的 `stats.exe`、AutoCAD 的 `accoreconsole.exe`，没一个在 PATH 里，第一次调用都得先找。它们的启动动辄七八秒，模型如果不知道，会反复调用、反复等。

**最麻烦的是多软件协同。** 科研工作流从来不是一个工具，是一串工具：GIS 出图 → R 做统计 → Python 跑模型 → Office 写稿。每个环节有自己的路径规则、编码假设、启动方式。模型既不知道该用哪个，也不知道上一个环节的输出能不能直接喂给下一个。于是每次你都得重新交代一遍："这个 xlsx 先用 Python 读进来，算完再交给 R 画图，注意别用 `readxl` 直接读，编码会炸。"

这不是"中文用户更辛苦"的情绪话，是客观差异：**他们的文档里不需要这几条，我们需要。** 所以结构可以抄，条目只能自己长出来。

## 我先走错了一步

最早我做的是一张大表。Python 路径、R 路径、装了哪些软件、常用命令、注意事项，全塞进去，两千多字，让它每次对话都读。

效果不好。它确实不再问 R 在哪了，但开始犯另一种错：表里明明写着"未装 pandoc"，它还是去试；明明写着"禁 pip"，赶时间的时候照样敲。

现在回头看，是两个问题叠在一起。**一是内容太长，关键条目被稀释了；二是我把"事实"和"禁令"混在了一张表里，而它们需要的强制力根本不一样。**

## 三张卡，按"多久变一次"分

后来我按一个很笨的维度重新分了一次：**不是按重要性，是按变动频率。**

| 卡 | 什么时候读 | 多久变一次 | 装什么 |
|---|---|---|---|
| `AGENTS.md` | 每一轮 | 几乎不变 | 一句话：什么时候去读卡 |
| 热卡 | 相关任务时 | 月级 | 路径、命令、禁令 |
| 冷卡 | 极少，报错才翻 | 只增不改 | 报错对照、领域知识 |

道理很简单：**常驻的内容必须最稳定，因为它每轮都占预算；变化最快的内容必须埋最深，因为没人会去翻一份天天在改的表。**

### 第一张：只留一句话

`AGENTS.md` 里只有一行，告诉它什么时候去读卡片本体。

```markdown
- 涉及本机路径、命令执行、文件读写，或遇到环境报错时，先读 `<TOOLS>\env-card.md`；
  该卡未覆盖时再读同目录 `env-ref.md`。
```

常驻的每一个字，每一轮对话都要重新读一遍。这句话省下来的不是磁盘空间，是**每一轮的注意力预算**。

代价是它得自己判断该不该读。有时候它该读没读，我得提醒一句。这招不是万能，我不打算把它说成万能。

### 第二张：热卡，和那行"未装什么"

热卡放常用的东西：几个固定路径、几条命令、几条禁令。

这里我做过一个当时觉得奇怪、后来觉得最值的决定——**专门写一行"未装什么"**。

未装 pandoc、未装 LaTeX、未装 QGIS、未装 WPS。

模型有个默认假设：环境是齐的。所以它会很自然地想"用 pandoc 转个格式""用 pdflatex 编译一下"。一句"未装"，能直接掐掉一整串注定失败的尝试。

为什么很少有人写这个？我猜是因为"我有什么"顺着想就出来了，"我没有什么"要多想一步。可恰恰是后者在浪费你的时间。

### 第三张：冷卡，平时不读

只在热卡没覆盖、或者报错的时候翻。里面主要放报错对照，一行一条：现象、根因、解法。

这一份最花时间，也是三份里唯一别人抄不走的——因为每条背后都是你这台机器上真实发生过的一次失败。

筛选标准我写死了三条：**能稳定复现、换个项目还会遇到、同类合并成一行。** 不满足的记在草稿里，不进表。

因为这张表一旦超过一屏，我自己就懒得看了。**一张没人看的表，等于没有。**

样张见 [`examples/windows-research-zh.md`](examples/windows-research-zh.md)。

## 有了卡之后，具体好在哪里

不说"提升效率"，说能看见的变化。

| 场景 | 没有卡 | 有卡之后 |
|---|---|---|
| 新开一个对话 | 先被问"R 装在哪"，再被问"Python 在哪" | 直接开工，不再从头介绍机器 |
| 要转个 PDF | 试 pandoc、试 LibreOffice、试 Word 导出，逐个失败 | 知道这台机器上该走哪条路 |
| 中文路径报 `No such file` | 一起排查半小时，怀疑文件、怀疑权限 | 直接给解法：拷到 ASCII 目录 |
| 跨软件衔接 | 每次重新交代"先用 Python 读，再给 R 画" | 按卡上固定的流程走 |
| 你个人的偏好 | 反复纠正同一件事 | 说一次，之后都按这个来 |
| 一周后回来 | 忘了上次为什么这么写 | 报错表里有当时的根因 |

省下来的其实是同一件东西：**你把"介绍我的机器"这件事，从每次对话都要做，变成一次做完。**

它不会让模型变聪明。它只是不再把时间花在重新认识环境上。

## 它治不好什么

写清楚这三条，比写十个优点有用。

1. **换台机器，全部作废。** 这是配置，不是软件，没有移植价值。
2. **全靠提示词。** 模型被追问、上下文又被填满的时候，还是会走捷径。真正的硬约束得靠沙箱和拦截，不是靠嘱咐。
3. **没有量化验证。** 我没做对照实验，所以"效率提升多少"这种话我说不出口。能确认的只有一句：同一类错误，不会出现第三次。

## 怎么用

1. 把 [`templates/`](templates) 下三个文件拷到你所用 Agent 的配置目录
2. 所有 `<...>` 占位符换成你机器上的真实路径
3. 第一周只维护热卡，遇到坑再往冷卡加
4. 别一次写全。写了用不上的条目，下次就懒得维护了——**卡的目标是短，不是全**

如果你已经在用 `AGENTS.md`：放心，两者不冲突。它管"常驻的约定"，这三份管"按需加载的本机事实"，分工不同。

## 文件说明

| 路径 | 作用 | 加载时机 |
|---|---|---|
| `templates/AGENTS.md` | 一行指针 | 常驻 |
| `templates/env-card.md` | 热卡：固定入口、命令、禁令、禁区 | 相关任务 |
| `templates/env-ref.md` | 冷卡：环境索引、本机机制、领域知识、报错对照 | 极少 |
| `examples/windows-research-zh.md` | 脱敏后的真实样张 | 阅读用 |

仓库里没有我自己的真卡。真卡里是本机绝对路径、用户名和软件清单，对别人没用，也不适合公开。
