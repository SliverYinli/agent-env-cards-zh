# 环境卡（冷卡）

> 按需读：只在热卡没说清、或命令执行报错时翻这里。
> **维护规则：只往第四节加行；一至三节尽量不动。** 最后验证：YYYY-MM-DD

## 一、环境索引（以"有没有"为主，版本号易变不记）

| 项 | 路径 / 说明 |
|---|---|
| Python 环境 | `<ENV>`；包缓存 `<PKG_CACHE>` |
| 常用第三方包 | 按需查：`conda list -p <ENV>` |
| 桌面软件 | 写名称即可，不写版本 |
| CLI 工具 | 哪些在 PATH、哪些不在（不在的要写定位方式） |
| 字体 | 公文字体、绘图字体的安装位置 |
| 文献库 | 数据库与附件目录 |

## 二、本机底层机制（改了会坏的东西）

记录那些一旦被"顺手优化"就会全盘失效的配置：

- 例如：某个 `sitecustomize.py` 注入了什么路径、锁定了哪些环境变量
- 例如：某个 `matplotlibrc` 预设了字体与负号，不要重复设置

## 三、领域知识（写一次、反复用的结构性问题）

不是本机专属，而是"每次都要重新查一遍"的专业知识。例如 Office 文档：

- `run` 拆分与跨 `run` 替换失效
- 域（`w:fldChar` / `w:instrText`）不能整段重写
- 字符缩进在 `w:ind/@w:leftChars`，清 `left_indent` 无效
